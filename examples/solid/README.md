# Solid example — `@surdeddd/bottom-sheet`

Minimal Solid + Vite playground using the `<BottomSheet>` component from
`@surdeddd/bottom-sheet/solid`. For the engine without a component, see the
vanilla example.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Files

- `src/App.tsx` — the sheet: three snap points, a header and a list.
- `src/main.tsx` — Vite entry, mounts via `solid-js/web` `render()`.
